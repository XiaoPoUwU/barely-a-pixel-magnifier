## 功能 / Features
- 放大鼠标周围像素
  - Magnify pixels around the mouse
- 显示物理坐标 / 逻辑坐标
  - Display physical coordinates / logical coordinates
- 显示对应坐标的颜色
  - Display the color of the corresponding coordinates
- 双击鼠标即可复制到剪贴板
  - Double-click the mouse to copy to clipboard

## 快捷键 / Shortcuts

鼠标左键拖动		移动窗口
Left mouse drag		Move window
鼠标右键		打开设置菜单	<-(没有什么功能)
Right mouse click	Open settings menu	<-(no features yet)
双击鼠标		复制当前坐标与颜色
Double click		Copy current coordinates & color
`-` (减号) 		减小截图范围
`-` (Minus)		Decrease capture area
`+` (等号) 	增大截图范围
`+` (Equal)		Increase capture area
`空格` 	暂停 / 恢复画面
`Space`		Pause / Resume screen
